📋 Istruzioni rapide

  1. Posiziona il nuovo file PDF nella cartella jesi/data/
  2. Apri il terminale e naviga in jesi/
  3. Esegui: python scripts/parse_report.py "data/nome-file.pdf"
  4. Ricarica la homepage per vedere le nuove news

💡 Lo script analizza il PDF, estrae titoli, descrizioni e fonti, e aggrega i nuovi articoli a quelli esistenti evitando duplicati.
